# 开发步骤规范

## 推进原则

每次只推进一个稳定小目标。完成一个目标后，必须更新开发日志并做验证，再进入下一步。

## 阶段 0：项目管理基线

- 创建 `docs/` 文档体系。
- 创建 `dev-logs/` 每日开发日志体系。
- 创建根目录工作指引。
- 明确后续开发节奏与质量标准。

## 阶段 1：后端最小可运行

- 建立 FastAPI 工程。
- 实现配置、数据库连接、基础表模型。
- 实现注册、登录、JWT 鉴权。
- 提供 `/api/models` 和 `/api/quotes`。
- 使用 SQLite 兜底完成启动验证。

## 阶段 2：模拟 Agent 与 SSE

- 实现模拟八类知识库。
- 实现 Agent 过程块生成。
- 实现 `/api/chat/stream` SSE 流式输出。
- 将用户消息、助手消息、检索块写入数据库。

## 阶段 3：前端基础页面

- 建立 React + TypeScript + Vite 工程。
- 实现登录、注册、介绍页。
- 实现路由、鉴权状态、API 客户端。

## 阶段 4：对话页

- 实现会话列表、消息历史、模型选择。
- 接入 SSE 流式输出。
- 实现过程块和长文本折叠。
- 加入底部文言名句轮滚。

## 阶段 5：联调与展示优化

- 完成前后端联调。
- 验证刷新后历史会话仍存在。
- 验证无真实 API Key 时可降级模拟。
- 修正移动端和桌面端布局问题。

## 阶段 6：真实服务预留

- 增加 OpenAI-compatible 配置说明。
- 保留接入真实检索模块的位置。
- 不在第一阶段强制依赖真实数据与 ChromaDB。
