# 项目需求规范

## 项目定位

`文渊问史` 是一个面向史籍知识问答的前后端分离 B/S 应用。系统用于演示 Agentic RAG 在多源异构古籍数据上的检索、决策与回答流程。

## 第一阶段目标

- 搭建可在浏览器运行的演示原型。
- 使用模拟知识库，不依赖真实数据文件夹存在。
- 保留未来接入真实检索模块、真实嵌入模型和真实大模型 API 的接口边界。
- 支持用户注册、登录、会话历史、模型选择、流式问答。
- 将模型思考摘要、决策过程、工具调用、检索知识、最终答案分块展示。

## 核心功能

- 用户系统：注册、登录、鉴权。
- 网站介绍：说明系统用途、数据类型、Agentic RAG 流程。
- 对话系统：类大语言模型聊天页面，支持历史会话和模型选择。
- 过程可视化：长文本默认折叠，用户点击后查看完整内容。
- 模拟知识库：覆盖人物、官职、地理、典故事件、术语、知识图谱、诗文、双语对照八类数据。
- 模型兼容：支持 OpenAI-compatible 配置；无密钥或调用失败时降级模拟 Agent。

## 暂不实现

- 不接入图片、图像生成或图片素材。
- 不同时实现 React 与 Vue。
- 不引入 Spring Boot。
- 不强制依赖真实 ChromaDB、真实嵌入模型或真实数据目录。
- 不暴露不可控的模型底层隐藏推理链，只展示产品化过程摘要和决策日志。
