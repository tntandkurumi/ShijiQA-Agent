# 前端设计规范

## 整体风格

- 风格关键词：古风、高端、雅致、克制、学术感。
- 不使用图片素材，视觉氛围通过排版、色彩、边框、阴影、动效完成。
- 避免花哨营销页，第一屏应直接体现史籍知识问答系统。

## 色彩建议

- 宣纸底色：`#f6f0df`
- 墨黑正文：`#211b17`
- 黛青主色：`#1f4d4a`
- 朱砂强调：`#9d2f25`
- 鎏金点缀：`#b58a42`
- 深色侧栏：`#17130f`

## 布局要求

- 登录/注册页：居中表单，背景保持文雅，不使用图片。
- 介绍页：简要说明系统能力、数据类型、Agentic RAG 流程。
- 对话页：左侧会话历史，中间聊天主区，顶部模型选择，消息内展示过程块。
- 底部固定或半固定区域展示文言名句轮滚。

## 过程展示

- 分块类型：意图识别、思考摘要、决策过程、工具调用、检索知识、最终答案。
- 每块必须有清晰标题、来源说明、时间或顺序信息。
- 超过阈值的文本默认折叠，按钮文案为“展开全文”“收起”。
- 检索知识块展示数据库类型、命中内容、相似度/分数、排序依据。

## 动效约束

- 允许：轻微淡入、打字流式输出、底部名句横向轮滚、按钮 hover。
- 避免：强闪烁、大面积旋转、过多渐变、影响阅读的复杂背景。
- 动效不得遮挡正文、输入框、按钮或过程块。
