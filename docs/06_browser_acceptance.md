# 浏览器验收清单

本清单用于阶段 5 人工验收。启动服务后，在浏览器访问：

```text
http://127.0.0.1:5173
```

## 启动方式

自动冒烟测试：

```powershell
.\scripts\smoke_test.ps1
```

推荐运行：

```powershell
.\scripts\start_dev.ps1
```

也可以分别运行：

```powershell
.\scripts\start_backend.ps1
.\scripts\start_frontend.ps1
```

## 基础页面

- 首页能打开，显示“文渊问史”介绍。
- 顶部导航不遮挡正文。
- 底部文言名句能滚动展示。
- 窄屏下导航、按钮、标题不重叠。

## 认证流程

- 可以注册新账号。
- 重复用户名会显示错误。
- 可以使用新账号登录。
- 登录后右上角显示用户名。
- 退出登录后访问 `/chat` 会回到登录页。

## 问答流程

- 登录后可以进入问答页。
- 可以新建会话。
- 可以删除会话，删除后该会话从左侧列表移除。
- 可以选择模型。
- 输入问题后，消息区出现用户消息和助手回答。
- 助手回答以流式方式逐步出现。
- 右侧出现过程可视化块。

## 过程可视化

- 过程块位于助手消息内部，不再单独占用右侧模块。
- 配置真实 LLM 后，过程块包含思考摘要、行动计划、工具调用、工具返回、最终回答。
- 未配置真实 LLM 时，不应显示伪造的思考过程，只显示真实模型状态提示与模拟检索数据。
- 检索知识块显示来源、标题、分数和排序依据。
- 长内容默认折叠，点击可展开全文。
- 多轮问答后，每条助手回答内部保留对应过程和检索依据。

## 历史持久化

- 刷新页面后，历史会话仍在左侧。
- 点击历史会话后，消息历史能恢复。
- 最近一轮过程块和检索块能恢复。

## 通过标准

以上条目均通过后，阶段 5 可视为完成。若出现布局重叠、接口报错、历史丢失或无法流式输出，记录到当日开发日志的“风险与阻塞”。
